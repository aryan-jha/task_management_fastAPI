1. Python Basics

This section covers the absolute foundation you need before DSA: variables, typing, I/O, indentation, comments, and the program entry pattern.

1.1 Variables

A variable is a name bound to an object in memory. Python does not make you declare a type, but for DSA code you should still write type hints.

name: str = "Aryan"
age: int = 22
price: float = 99.5
active: bool = True

print(name)    # Aryan
print(age)     # 22
print(price)   # 99.5
print(active)  # True

You can rebind a name to a new value (and even a new type), but that is usually poor style in DSA solutions:

x = 10
x = "now a string"  # allowed, but avoid this in interview code
DSA habit: Prefer clear names like left, right, freq, stack over single letters except for loop indices.

1.2 Type hints

Type hints document intent. Python does not enforce them at runtime.

arr: list[int] = [1, 2, 3]
frequency: dict[int, int] = {}
point: tuple[int, int] = (3, 4)
visited: set[int] = set()
maybe_value: int | None = None

print(arr)         # [1, 2, 3]
print(frequency)   # {}
print(point)       # (3, 4)
print(visited)     # set()
print(maybe_value) # None

Useful modern forms:

from collections.abc import Callable, Iterator

nums: list[int] = [10, 20]
mapping: dict[str, list[int]] = {"odds": [1, 3], "evens": [2, 4]}
pair: tuple[str, int] = ("Aryan", 90)
op: Callable[[int], int] = lambda x: x * 2

print(mapping["odds"])  # [1, 3]
print(op(5))            # 10

9.7 Two Sum (classic hashmap pattern)

def two_sum(nums: list[int], target: int) -> list[int]:
    seen: dict[int, int] = {}
    for i, value in enumerate(nums):
        complement: int = target - value
        if complement in seen:
            return [seen[complement], i]
        seen[value] = i
    return []

print(two_sum([2, 7, 11, 15], 9))  # [0, 1]
print(two_sum([3, 2, 4], 6))       # [1, 2]

TC: O(n) average. SC: O(n).

# BFS skeleton
from collections import deque

def bfs(start: int, graph: dict[int, list[int]]) -> list[int]:
    order: list[int] = []
    seen: set[int] = {start}
    q: deque[int] = deque([start])
    while q:
        node = q.popleft()
        order.append(node)
        for nei in graph.get(node, []):
            if nei not in seen:
                seen.add(nei)
                q.append(nei)
    return order

g = {0: [1, 2], 1: [0, 3], 2: [0], 3: [1]}
print(bfs(0, g))  # [0, 1, 2, 3]

19.4 __init__ vs __new__

__new__ creates (allocates) the instance and returns it. __init__ then initializes it and must return None. You almost always override __init__; override __new__ for immutables, singletons, or subclassing immutable builtins.

class Tracer:
    def __new__(cls, *args, **kwargs):
        print("1. __new__ creates instance")
        return super().__new__(cls)

    def __init__(self, value: int) -> None:
        print("2. __init__ initializes")
        self.value = value

t = Tracer(10)

# 2. __init__ initializes

class UpperStr(str):
    def __new__(cls, value: str):
        return super().__new__(cls, value.upper())

print(UpperStr("hello"))  # HELLO
Trap: If __new__ returns an object that is not an instance of cls, __init__ is not called.

        return "B->" + super().ping()

class C(A):
    def ping(self) -> str:
        return "C->" + super().ping()

class D(B, C):  # diamond: D -> B -> C -> A
    def ping(self) -> str:
        return "D->" + super().ping()

print(D().ping())       # D->B->C->A
print(D.mro())
# [<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>]

MRO (Method Resolution Order) uses the C3 linearization algorithm. Class.mro() / Class.__mro__ shows the search order. super() does not mean “parent class” blindly — it means “next class in the MRO”.

23.3 Arithmetic & reflected / in-place ops

For a + b: try a.__add__(b); if NotImplemented, try b.__radd__(a). In-place a += b uses __iadd__ if present.

class Vector:
    def __init__(self, x: float, y: float) -> None:
        self.x, self.y = x, y

    def __repr__(self) -> str:
        return f"Vector({self.x}, {self.y})"

    def __add__(self, other):
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, k):
        if not isinstance(k, (int, float)):
            return NotImplemented
        return Vector(self.x * k, self.y * k)

    def __rmul__(self, k):
        return self.__mul__(k)

    def __iadd__(self, other):
        self.x += other.x
        self.y += other.y
        return self

    def __neg__(self):
        return Vector(-self.x, -self.y)

    def __abs__(self):
        return (self.x ** 2 + self.y ** 2) ** 0.5

v = Vector(1, 2) + Vector(3, 4)
print(v)            # Vector(4, 6)
print(3 * Vector(2, 1))  # Vector(6, 3)
v2 = Vector(1, 1)
v2 += Vector(1, 0)
print(v2, abs(v2))  # Vector(2, 1) 2.236...

23.4 Container / sequence protocol

class Bag:
    def __init__(self, items=None) -> None:
        self._items = list(items or [])

    def __len__(self) -> int:
        return len(self._items)

    def __getitem__(self, index):
        return self._items[index]

    def __setitem__(self, index, value) -> None:
        self._items[index] = value

    def __delitem__(self, index) -> None:
        del self._items[index]

    def __contains__(self, item) -> bool:
        return item in self._items

    def __iter__(self):
        return iter(self._items)

    def __reversed__(self):
        return reversed(self._items)

b = Bag([10, 20, 30])

b[1] = 99
print(list(b), list(reversed(b))) # [10, 99, 30] [30, 99, 10]

24.1 Descriptors (the mechanism behind @property, methods, classmethod)

A descriptor is any object defining __get__, and optionally __set__/__delete__. Data descriptors (with __set__/__delete__) override instance dict. Non-data descriptors (only __get__) can be shadowed by instance attributes.

class Positive:
    def __set_name__(self, owner, name):
        self.public_name = name
        self.private_name = f"_{name}"

    def __get__(self, obj, objtype=None):
        if obj is None:
            return self
        return getattr(obj, self.private_name)

    def __set__(self, obj, value):
        if value <= 0:
            raise ValueError(f"{self.public_name} must be positive")
        setattr(obj, self.private_name, value)

class Product:
    price = Positive()
    qty = Positive()

    def __init__(self, price: float, qty: int) -> None:
        self.price = price
        self.qty = qty

p = Product(10, 2)
print(p.price, p.qty)  # 10 2
# Product(-1, 2)       # ValueError
Interview: Functions are non-data descriptors — that is why obj.method becomes a bound method via function.__get__.

24.2 Metaclasses

A metaclass is the class of a class. Default metaclass is type. Use metaclasses for APIs that must rewrite class creation (ORMs, validation frameworks). Prefer __init_subclass__ / decorators when possible.

class Meta(type):
    def __new__(mcls, name, bases, namespace):
        namespace["created_by"] = "Meta"
        cls = super().__new__(mcls, name, bases, namespace)
        print("creating", name)
        return cls

class Service(metaclass=Meta):
    def run(self) -> str:
        return "ok"

# creating Service
print(Service.created_by)  # Meta
print(type(Service))       # <class '__main__.Meta'>
print(Service().run())     # ok

24.6 Equality patterns for domain objects

class Money:
    def __init__(self, amount: int, currency: str) -> None:
        self.amount = amount
        self.currency = currency

    def __eq__(self, other):
        if not isinstance(other, Money):
            return NotImplemented
        return self.amount == other.amount and self.currency == other.currency

    def __hash__(self):
        return hash((self.amount, self.currency))

print(Money(10, "INR") == Money(10, "INR"))  # True
print({Money(10, "INR"), Money(10, "INR")})  # one element set

class Singleton:
    _instance = None

    def __new__(cls):
        if cls._instance is None:

25. OOP Interview Guide (Q&A + Drills)

This section is written for verbal interviews and coding rounds. Learn the short answer, then the precise Python nuance.

25.1 Core theory questions

Q1. What is OOP? Why use it?

Answer: Organize code around objects that combine data and behavior. Benefits: encapsulation, reuse via inheritance/composition, polymorphism for extensible APIs. Cost: over-abstraction can hurt clarity — especially in short DSA scripts.

Q2. Class vs object vs instance?

Answer: Class = blueprint/type. Object/instance = concrete value created from a class. In Python, the class object itself is an object (instance of its metaclass, usually type).

Q3. What is self?

Answer: Explicit first parameter of instance methods referring to the instance. Bound methods inject it automatically. Name is convention.

Q4. __init__ vs constructor?

Answer: In Python the true constructor is __new__ + __init__. __new__ allocates/returns instance; __init__ initializes. People loosely call __init__ the constructor.

Q5. Instance vs class vs static methods?

Answer: Instance: needs self. Classmethod: receives cls — good factories. Staticmethod: no self/cls — namespaced function.

class Demo:
    def inst(self): return "inst", self
    @classmethod
    def cls(cls): return "cls", cls
    @staticmethod
    def st(): return "st"

d = Demo()
print(d.inst()[0], Demo.cls()[0], Demo.st())  # inst cls st

Q6. Explain encapsulation in Python

Answer: No hard private members. Use _name convention, __name mangling, and @property for controlled access.

Q7. What is MRO? Diamond problem?

Answer: Method Resolution Order decides which parent method runs under multiple inheritance. Python uses C3 linearization. Diamond problem is solved by a consistent MRO; super() cooperates along that order.

class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass
print([c.__name__ for c in D.mro()])  # D B C A object

Q8. Inheritance vs composition?

Answer: Inheritance = is-a / polymorphic substitution. Composition = has-a / reuse by delegation. Prefer composition for flexible designs; inheritance for shared interface/behavior hierarchies.

Q9. What is polymorphism in Python?

Answer: Duck typing + method overriding + operator overloading via dunders. Explicit interfaces via Protocol/ABC when you want stronger contracts.

Q10. Abstract class vs interface?

Answer: Python has no separate interface keyword. ABC with @abstractmethod approximates abstract base / interface. Protocol gives structural typing.

25.2 Decorator interview cluster

Q11. What is a decorator?

Answer: A callable wrapping another callable to add cross-cutting behavior. @f means assignment name = f(name) at definition time.

Q12. Why functools.wraps?

Answer: Copies metadata (__name__, __doc__, annotations) from original to wrapper — critical for debugging and introspection.

Q13. Stacking order?

Answer: Closest decorator applies first: @a above @b means a(b(func)).

Q14. Decorator with arguments?

Answer: Write a factory that returns the real decorator: @repeat(3) → repeat(3)(func).

25.3 Dunder interview cluster

Q15. __str__ vs __repr__?

Answer: str → readable; repr → unambiguous/debug (ideally eval-able). print uses str if present else repr. Containers use repr of elements.

Q16. Why did my object become unhashable after writing __eq__?

Answer: CPython sets __hash__ = None when __eq__ is user-defined, unless you define a compatible __hash__. Needed for set/dict keys.

Q17. Difference __getattr__ vs __getattribute__?

Answer: __getattribute__ intercepts all lookups; __getattr__ only on missing attributes. Careless __getattribute__ causes infinite recursion.

Q18. How does with work?

Answer: Calls __enter__, runs block, then __exit__ with exception triple. Can also use contextlib.contextmanager.

Q19. What are descriptors?

Answer: Objects with __get__/__set__/__delete__ stored on a class. Mechanism for property, bound methods, managed attributes.

Q20. What is a metaclass? When use it?

Answer: “Class of a class.” Customize class creation. Rare in app code; common in frameworks. Prefer class decorators / __init_subclass__ first.

# Drill sample solution: @timeit
from functools import wraps
import time

def timeit(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        t0 = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            ms = (time.perf_counter() - t0) * 1000
            print(f"{func.__name__}: {ms:.3f} ms")
    return wrapper

@timeit
def work():
    return sum(range(10000))

print(work())  # work: ... ms  then 49995000
